PYTHON BASIC TASKS - CSE Lab Assignment

- Python 3.10+
- Jupyter Notebook
- No external dependencies
QUICK START
1. Clone: git clone https://github.com/abhishekwalikar-pixel/Python_tasks.git
2. Open: jupyter notebook python_basic_tasks.ipynb
3. Run: Cell → Run All
